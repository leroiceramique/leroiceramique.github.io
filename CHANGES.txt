[11] نظام الفئات: بائع / عامل مخزون / مدير بوت / بائع خارجي (جديد)
------------------------------------------------------
- المستخدم الجديد عند طرق باب البوت لأول مرة يختار فئته:
  🛍 بائع | 📦 عامل مخزون | 🧑‍💼 مدير البوت | 🌍 بائع خارجي
- الفئة المطلوبة تُحفظ في قاعدة البيانات (requested_role)
  ويصل المدير إشعار يعرضها مع 3 أزرار: تفعيل بالفئة /
  تفعيل كعميل / رفض.
- الموافقة تمنح الصلاحية بناءً على الفئة المختارة تلقائياً.
- كل فئة لها لوحة أزرار خاصة بها:
  • عامل المخزون: إضافة/كميات/تعديل/مخزون منخفض/حركة/
    طلبات توريد/معلقة/غير المشحونة — بلا مستخدمين أو
    نسخ احتياطي أو فواتير أو حذف.
  • البائع: إنشاء فاتورة + طلب توريد + طلباتي + المعلقة
    + غير المشحونة (حسب الصلاحية الفردية).
  • البائع الخارجي (المنافس): بحث التوفر فقط (متوفر/
    محدود/غير متوفر) دون كميات أو أسعار.
  • مدير البوت: كامل صلاحيات الإدارة.
- بوابة حماية داخل مسار الإدارة: حتى لو كتب شخص نص زر
  يدوياً دون أن تكون فئته تسمح → يُرفض صراحة.
- لوحة المستخدمين: عدّادات لكل فئة + أيقونة الفئة لكل
  مستخدم + زر 🎯 الفئة لكل مستخدم يفتح قائمة تغيير
  الفئة (بديل شامل للترقية/الإزالة) — المستخدمين
  الحاليين يُقسمون من هنا.
- إشعار المستخدم عند تغيير فئته + لوحته الجديدة تظهر فور
  الضغط على القائمة الرئيسية أو /start.
- الترقية قاعدة بيانات: عمود requested_role + قيد أدوار
  كامل (ترقية idempotent عند كل إقلاع تُصلح القواعد القديمة).
- البث (التنبيه/إشعار التحديث) وقائمة عمال الفاتورة تشمل
  كل الفئات المفعّلة الآن.
- اختبار وظيفي 7/7 للفئات + فحص QA مُقوّى (يثبت ثوابت
  ROLE_) + py_compile سليم.
