تحديث v208 — كل زر من لوحة الإعدادات يعرض المطلوب منه فقط
==========================================================

بلاغك: «عند الضغط على خيار الملف الشخصي يعرض كل شيء حتى الثيمات
والتحديثات — من المفروض كل زر يعرض المطلوب فقط منه».

الآن:
  • 👤 الملف الشخصي → الصورة الشخصية والاسم المعروض واسم الدخول فقط.
  • 🎨 الثيمات → بطاقة الثيم وحدها.
  • 🔄 التحديثات → بطاقة التحديث وحدها مع فحص فوري.
  • زر «↩ رجوع» يعيدك إلى الشاشة التي فتحت منها اللوحة.

الملفات (ارفعها للمستودع بنفس المسار):
  1. bot.py        → الختم 85 (يجدد كاش الواجهة تلقائياً عند الإقلاع)
  2. pwa.html      → وضع البطاقة الواحدة + زر الرجوع
  3. CHANGELOG.md  → سجل v208
  4. app_version.json → نسخة التطبيق 906
