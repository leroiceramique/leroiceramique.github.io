# بوت تيليجرام لإدارة المخزون

بوت احترافي لإدارة مخزون مخزن سلع يخدم عدة محلات عبر تيليجرام.

## المميزات

- **نظام صلاحيات مزدوج:** مديرون بصلاحيات كاملة + عملاء (محلات) ببحث فقط
- **لوحة تحكم بالأزرار:** Reply Keyboard سهلة الاستخدام للمديرين
- **بحث ذكي:** بحث بجزء من الاسم مع دعم العربية (ILIKE)
- **تنبيهات تلقائية:** تنبيه المديرين عند وصول كمية سلعة للحد الأدنى
- **سجل عمليات:** تتبع كامل لكل عملية إدخال وإخراج
- **أمان:** لا تظهر الكميات للعملاء، فقط للمديرين
- **يعمل 24/7:** استضافة مجانية على Render مع Webhook أو Polling + Health Server

## خطوات التشغيل المحلي

### 1. إنشاء البوت

1. افتح [@BotFather](https://t.me/BotFather) في تيليجرام
2. أرسل `/newbot` واتبع التعليمات
3. احصل على **BOT_TOKEN**
4. احصل على **Telegram ID** من [@userinfobot](https://t.me/userinfobot)

### 2. إعداد قاعدة البيانات (Supabase)

1. أنشئ حساباً مجانياً على [supabase.com](https://supabase.com)
2. أنشئ مشروعاً جديداً
3. اذهب إلى **Settings > Database > Connection string**
4. انسخ رابط **URI** (الصيغة: `postgresql://postgres.[ref]:[password]@...`)
5. فعّل **Connection Pooling** واستخدم رابط الـ Pooler

### 3. تشغيل المشروع

```bash
# استنساخ المشروع
git clone https://github.com/your-username/telegram-inventory-bot.git
cd telegram-inventory-bot

# إنشاء بيئة افتراضية
python -m venv venv
source venv/bin/activate  # Linux/Mac
# أو: venv\Scripts\activate  # Windows

# تثبيت المكتبات
pip install -r requirements.txt

# إعداد متغيرات البيئة - أنشئ ملف .env
# BOT_TOKEN=your_bot_token
# DATABASE_URL=postgresql://...
# ADMIN_IDS=123456789
# WEBHOOK_URL=  (اتركه فارغاً للتشغيل المحلي)

# تشغيل البوت
python bot.py
```

## النشر على Render (مجاني)

### الطريقة الأولى: عبر لوحة التحكم

1. أنشئ حساباً على [render.com](https://render.com)
2. اضغط **New > Web Service**
3. اربط مستودع GitHub الخاص بك
4. عدّل الإعدادات:
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python bot.py`
   - **Runtime:** Python 3
5. أضف متغيرات البيئة:
   - `BOT_TOKEN` = توكن البوت
   - `DATABASE_URL` = رابط Supabase
   - `ADMIN_IDS` = معرفات المديرين (مفصولة بفواصل)
   - `WEBHOOK_URL` = `https://your-app.onrender.com` (بدون /webhook)
   - `PORT` = `10000`
6. اضغط **Create Web Service**

### الطريقة الثانية: عبر render.yaml

1. ارفع `render.yaml` مع المشروع
2. في Render، اضغط **New > Blueprint**
3. اختر المستودع
4. سيتم قراءة الإعدادات تلقائياً
5. أضف متغيرات البيئة من لوحة التحكم

### ملاحظات مهمة لـ Render

- **البوت يعمل 24/7 تلقائياً** بفضل نظام Keep-Alive المدمج الذي يبقي الخدمة نشطة
- عند كل نشر جديد، يتغير عنوان Webhook. تأكد من تحديث `WEBHOOK_URL`

## صلاحيات المستخدمين

### المدير (Admin)
| الأمر / الزر | الوظيفة |
|-------------|---------|
| `/add` أو 📦 إضافة سلعة | إضافة سلعة جديدة |
| ➕ إضافة كمية | إضافة كمية لسلعة موجودة |
| ➖ إخراج كمية | إخراج (خصم) كمية من سلعة |
| ✏️ تعديل سلعة | تعديل اسم/مكان/حد أدنى |
| 🗑️ حذف سلعة | حذف سلعة نهائياً |
| 🔍 بحث | بحث في المخزون |
| 📊 تقرير المخزون | عرض كل السلع بالتفاصيل |
| 📜 سجل العمليات | آخر 20 عملية |
| ❌ إلغاء | إلغاء أي عملية جارية |

### العميل (المحل)
| الإجراء | الوظيفة |
|---------|---------|
| إرسال اسم سلعة | معرفة التوفر (متوفر / غير متوفر) |

## أمثلة الاستخدام

### المدير يضيف سلعة:
```
المدير: /add
البوت: 📦 أرسل اسم السلعة:
المدير: زيت 5 لتر
البوت: 📦 زيت 5 لتر
       📦 كم عدد العلب (crt)?
المدير: 50
البوت: 📋 تأكيد إضافة سلعة:
       📦 الاسم: زيت 5 لتر
       📦 العلب: 50 crt
       [✅ تأكيد] [❌ إلغاء]
المدير: [يضغط ✅ تأكيد]
البوت: ✅ تمت إضافة السلعة بنجاح!
```

### المدير يضيف كمية:
```
المدير: [يضغط ➕ إضافة كمية]
البوت: 📦 قائمة السلع...
       #1 زيت 5 لتر — الكمية: 50
المدير: 1, 25
البوت: ✅ تمت إضافة 25 لـ "زيت 5 لتر"
          الكمية: 75
```

### العميل يبحث:
```
المحل: زيت
البوت: 📦 زيت 5 لتر
       🟢 متوفر

       📦 زيت 2 لتر
       🔴 غير متوفر حالياً

       📦 زيت ذرة
       🟡 كمية محدودة
```
