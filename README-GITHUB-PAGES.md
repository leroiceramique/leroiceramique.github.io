# 🚀 نشر تطبيق «مُخزون السيراميك» على GitHub Pages — الرابط leroiceramique.github.io

هذه الحزمة تجعل **الصفحة نفسها هي التطبيق الكامل** — تُفتح من رابط ثابت على أي حاسوب أو هاتف، وتتصل بخادم Render مباشرة (بلا أي نافذة أخرى ولا تحويل).

## 📦 ملفات النشر المطلوبة (من هذا المجلد)
| الملف | وظيفته |
|---|---|
| `index.html` | التطبيق كامل بواجهته الاحترافية (شريط جانبي + بطاقات مؤشرات + بحث علوي) — **الملف الأساسي** |
| `manifest.webmanifest` | إعدادات تطبيق PWA |
| `sw.js` | عامل الخدمة (شبكة أولاً — يمرّر نداءات API للخادم مباشرة) |
| `icon.jpg` | أيقونة التطبيق |

ملاحظة: ملفات الصور `preview_*.png` و`theme_*.png` لقطات للواجهة فقط — رفعها اختياري ولا يؤثر على التشغيل. ملف `README-DEPLOY.txt` ملاحظة توليد آلي.

## ✅ خطوات النشر (مرة واحدة — 5 دقائق)

1. **حساب GitHub**: ادخل github.com بحساب اسمه `leroiceramique`
   (إن كان اسم حسابك مختلفاً، الرابط سيصبح `https://اسم-حسابك.github.io` — والصفحة تعمل بنفس الطريقة).
2. **إنشاء المستودع**: اضغط **New repository** وسمّه **بالضبط**: `leroiceramique.github.io`
   - اختر **Public** ← **Create repository**.
3. **رفع الملفات**: في صفحة المستودع اضغط **uploading an existing file** (أو Add file ← Upload files)
   - اسحب الملفات الأربعة: `index.html` + `manifest.webmanifest` + `sw.js` + `icon.jpg` ← **Commit changes**.
4. **تفعيل الصفحة**: Settings ← Pages ← Source: **Deploy from a branch** ← Branch: **main** ← Save.
5. بعد دقيقة افتح: **https://leroiceramique.github.io**

## 🔗 ربط التطبيق بخادم Render (مرة واحدة لكل جهاز)

- عند أول فتح تظهر شاشة **«ربط التطبيق بالخادم»** — أدخل عنوان خادم Render
  (مثال: `https://your-bot.onrender.com`) — يتحقق التطبيق من الخادم حياً ثم **يُفتح في نفس الصفحة**.
- العنوان يُحفظ في الجهاز؛ كل جهاز جديد يدخله مرة واحدة فقط.
- من لديه نسخة قديمة محفوظ فيها عنوان بوابة سابق (`leroi_server_url`) — يُرحَّل تلقائياً بلا إعادة إدخال.

## 🛡️ حماية الجلسة عبر النطاقين

- الاتصال من `github.io` إلى `onrender.com` يستعمل ترويسة **`X-Session-Token`** بدل الكوكيز
  (المتصفحات تحجب كوكيز الطرف الثالث)، وCORS في الخادم مقيّد بالأصل المسموح فقط.
- لإضافة أصول أخرى في الخادم: متغير البيئة `PWA_ALLOWED_ORIGINS` مفصولة بفواصل.
- الجلسات 90 يوماً وتذكّر الدخول 180 يوماً — كما هي تماماً، ولا علاقة بينها وبين تحديثات الواجهة.

## 🔄 التحديث لاحقاً

- **تحديث `bot.py` على Render فقط** → لا حاجة لإعادة رفع Pages؛ نسخة الخادم تُقدّم الواجهة بأحدث الرقع
  وتطبيق PWA يتحدّث تلقائياً (الإصدار يظهر في الإعدادات).
- **تحديث واجهة Pages نفسها** → ولّد الملفات من جديد: `python bot.py --export-pages --api-root https://your-bot.onrender.com`
  ثم ارفع `index.html` المولّد (و`sw.js` إن تغيّر).

## ❓ يعمل / لا يعمل

- **404** → Pages غير مفعّلة، أو المستودع ليس عاماً، أو اسم المستودع ليس `leroiceramique.github.io` بالضبط.
- **«تعذّر الاتصال بالخادم»** عند أول إدخال → خادم Render نائم (الباقة المجانية تستيقظ خلال 30–60 ثانية) — أعد المحاولة.
- **طلب عنوان الخادم من جديد** → طبيعي فقط على جهاز جديد أو بعد مسح بيانات المتصفح.
