 ابدأ هنا — تحديث v54 (تسجيل مثل واتساب + معرض مباشر + دليل كروم)
═══════════════════════════════════════════════════════

نفس التطبيق الذي اخترناه — تحديث من الداخل، لا APK جديد.

ماذا يفعل هذا التحديث؟
─────────────────────────────────────────
1) التسجيل بالضغط المطول مثل واتساب: 🎤 ضغط وتكلم وأفلت فيُرسل،
   وسحب الإصبع بعيداً يلغي.
2) اكتشفنا أن أيقونة التطبيق الحالية لا تمرر الميكروفون أصلاً
   (لهذا كان يفتح الملفات) — أضفنا دليلاً بزر «🚀 فتح في كروم
   الآن» يفعّل التسجيل الكامل في دقيقة وبدون تثبيت أي شيء،
   مرة واحدة فقط.
3) زر 🖼️ يفتح معرض الصور مباشرة، وقائمة إرفاق أسرع.

الخطوات (نفس طريقتك المعتادة في Render):
─────────────────────────────────────────
1) فك الضغط — ستجد 5 ملفات.
2) افتح لوحة Render ← خدمتك (produit).
3) ارفع الملفين:
      bot.py     ← مكان bot.py القديم
      pwa.html   ← مكان pwa.html القديم
   (الملفات الثلاثة الباقية للمرجع فقط — لا ترفعها)
4)Render سيعيد التشغيل وحده (دقيقتان تقريباً).
5) في التطبيق ستظهر شارة «يتوفر تحديث v54» ← اضغط نعم.
6) بعد التحديث: الإعدادات ← «🎤 تفعيل التسجيل مثل واتساب»
   واتبع 3 خطوات لتفعيل الصوت والكاميرا بالكامل عبر كروم.
