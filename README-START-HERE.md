 ابدأ هنا — تحديث v53 (الحل النهائي للمكرر + حذف المحادثة + الأذونات)
═══════════════════════════════════════════════════════

نفس التطبيق الذي اخترناه — تحديث من الداخل، لا APK جديد.

ماذا يفعل هذا التحديث؟
─────────────────────────────────────────
1) حل نهائي للاسم المكرر (مثل Mostafa): زر «🧬 دمج الحساب
   المكرر» في لوحة المستخدمين بالبوت — يدمج الحسابين في
   حساب واحد وينقل كل شيء (المحادثات، الحركات، الفواتير،
   طلبات التوريد، دخول التطبيق) ثم يوقف المكرر نهائياً.
2) زر 🗑️ داخل كل محادثة لحذفها بالكامل عند الطرفين.
3) التسجيل الصوتي: إن مُنع الميكروفون المباشر يُفتح مسجّل
   الهاتف تلقائياً ويُرسل التسجيل فوراً — بلا أي رسالة فشل.
   + فيديو وكاميرا مباشرة وقائمة إرفاق أوسع وحد 25 ميغابايت.

الخطوات (نفس طريقتك المعتادة في Render):
─────────────────────────────────────────
1) فك الضغط — ستجد 5 ملفات.
2) افتح لوحة Render ← خدمتك (produit).
3) ارفع الملفين:
      bot.py     ← مكان bot.py القديم
      pwa.html   ← مكان pwa.html القديم
   (الملفات الثلاثة الباقية للمرجع فقط — لا ترفعها)
4) اضغط Save Manual Deploy / Deploy وانتظر أن تصبح الحالة Live
   (دقيقتان إلى 4 دقائق).
5) افتح التطبيق من هاتفك:
   • ستظهر شارة «يتوفر تحديث v53» ← اضغط «إعادة تحميل».
   • إن لم تظهر: أغلق التطبيق وافتحه من جديد.
6) لدمج Mostafa نهائياً:
   • بوت تلجرام ← أمر /users ← ستجد تحت اسم Mostafa زر
     «🧬 دمج الحساب المكرر» ← اضغطه ← اختر الحساب المكرر
     من القائمة ← «✅ نعم، ادمج الآن».
   • افتح «الرسائل 💬» في التطبيق: الاسم صار مرة واحدة فقط.
7) لتجربة الجديد:
   • 🗑️ أعلى أي محادثة = حذفها بالكامل.
   • 🎤 = تسجيل صوتي (وإن مُنع الإذن يفتح مسجّل الهاتف فوراً).
   • 📎 = صورة / فيديو / ملف صوتي / كاميرا مباشرة / ملف آخر.

إن واجهت أي عائق:
─────────────────
• صفحة لا تفتح؟ انتظر دقيقتين (السيرفر المجاني يستيقظ ببطء
  بعد كل نشر) ثم أعد المحاولة.
• «رسالة قديمة» أو شاشة دخول؟ ادخل باسمك وكلمتك كالمعتاد
  — مرة واحدة فقط، والتطبيق سيتذكرك بعدها.
• لتفعيل الميكروفون والكاميرا المباشرة (اختياري):
  إعدادات الهاتف ← التطبيقات ← تطبيق/متصفح LE ROI ← الأذونات
  ← اسمح بالميكروفون والكاميرا.
