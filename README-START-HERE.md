 ابدأ هنا — تحديث v52 (دمج الحسابات المتشابهة)
═══════════════════════════════════════════════════════

نفس التطبيق الذي اخترناه — تحديث من الداخل، لا APK جديد.

ماذا يفعل هذا التحديث؟
─────────────────────────────────────────
من ظهر اسمه مرتين (لأنه سجّل من تلجرام ومن التطبيق) سيصبح
اسماً واحداً تلقائياً بعد هذا التحديث — وكل محادثاته وحركاته
ودخوله بالتطبيق تنتقل لحسابه الموحّد دون فقدان شيء.
والشخص الجديد كلياً يُفتح له حساب عادي كما هو.

الخطوات (نفس طريقتك المعتادة في Render):
─────────────────────────────────────────
1) فك الضغط — ستجد 5 ملفات.
2) افتح لوحة Render ← خدمتك (produit).
3) ارفع الملفين:
      bot.py     ← مكان bot.py القديم
      pwa.html   ← مكان pwa.html القديم
   (الملفات الثلاثة الباقية للمرجع فقط — لا ترفعها)
4) اضغط Save Manual Deploy / Deploy وانتظر أن تصبح الحالة Live
   (دقيقتان إلى 4 دقائق) — الدمج يحدث تلقائياً مع أول إقلاع.
5) افتح التطبيق من هاتفك:
   • ستظهر شارة «يتوفر تحديث v52» ← اضغط «إعادة تحميل».
   • إن لم تظهر: أغلق التطبيق وافتحه من جديد.
6) افتح «الرسائل 💬» ← «محادثة جديدة»: ستجد كل اسم مرة واحدة فقط.

إن واجهت أي عائق:
─────────────────
• صفحة لا تفتح؟ انتظر دقيقتين (السيرفر المجاني يستيقظ ببطء
  بعد كل نشر) ثم أعد المحاولة.
• «رسالة قديمة» أو شاشة دخول؟ ادخل باسمك وكلمتك كالمعتاد
  — مرة واحدة فقط، والتطبيق سيتذكرك بعدها.
• إن بقي اسمان متشابهان (حسابان فعليان في تلجرام بنفس الاسم):
  هذا مقصود — قرر بنفسك أيهما الزائد وأوقفه من بوت تلجرام
  ← لوحة المستخدمين ← زر الطرد 🚫.
