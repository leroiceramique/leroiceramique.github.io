 ابدأ هنا — تحديث v60 (إصلاح الميكروفون + بديل مضمون)
═══════════════════════════════════════════════════════

نفس التطبيق — تحديث من الداخل، لا APK جديد.

ماذا يفعل هذا التحديث؟
─────────────────────────────────────────
1) 🔧 إصلاح تلقائي بضغطة — يعيد تشغيل محرك الصوت داخل
   التطبيق فوراً.
2) 🎙️ بديل مضمون — تسجيل بمسجّل الهاتف نفسه (نفس مسار
   واتساب) وإرسال الملف في الدردشة. يعمل دائماً.
3) فحص ذكي يجرب مسارين ويعتمد الذي ينجح على جهازك
   تلقائياً + تسخين محرك الصوت قبل كل تسجيل.

الخطوات (نفس طريقتك المعتادة في Render):
─────────────────────────────────────────
1) فك الضغط — ستجد 5 ملفات.
2) افتح لوحة Render ← خدمتك (produit).
3) ارفع الملفين:
      bot.py     ← مكان bot.py القديم
      pwa.html   ← مكان pwa.html القديم
   (الملفات الثلاثة الباقية للمرجع فقط — لا ترفعها)
4) Render سيعيد التشغيل وحده (دقيقتان تقريباً).
5) في التطبيق: شارة «يتوفر تحديث v60» ← «نعم، حدّث الآن».

تجربة سريعة بعد التحديث:
─────────────────────────────────────────
اضغط 🎤 مطولاً — إن فشل تفتح لوحة الفحص وحدها:
«🔍 فحص الآن» ثم «🔧 الإصلاح التلقائي» ثم أعد الفحص.
وبديل مضمون دائماً: «🎙️ تسجيل بمسجّل الهاتف».

هل أحتاج تثبيت أي شيء على الهاتف؟
─────────────────────────────────────────
لا. التحديث يصل من داخل التطبيق بنقرة «نعم، حدّث الآن»
كالعادة — نفس الأيقونة، نفس الدخول، بلا أي تنزيل جديد.
