 ابدأ هنا — تحديث v58 (إعادة بناء قسم الرسائل)
═══════════════════════════════════════════════════════

نفس التطبيق الذي اخترناه — تحديث من الداخل، لا APK جديد.

ماذا يفعل هذا التحديث؟
─────────────────────────────────────────
1) الفيديو يُشغَّل داخل الدردشة (بطاقة ▶ ثم مشغل مدمج).
2) الرسائل تبقى محفوظة: تاريخ كامل + فتح فوري من الذاكرة
   حتى بعد التحديث أو خروج/دخول.
3) محادثة جديدة = كل المستخدمين (تطبيق/تلغرام) مع بحث
   وحالة اتصال «متصل الآن».
4) إرسال فوري الظهور + تحديث أسرع + الصوت مثل واتساب
   حرفياً كما هو.

الخطوات (نفس طريقتك المعتادة في Render):
─────────────────────────────────────────
1) فك الضغط — ستجد 5 ملفات.
2) افتح لوحة Render ← خدمتك (produit).
3) ارفع الملفين:
      bot.py     ← مكان bot.py القديم
      pwa.html   ← مكان pwa.html القديم
   (الملفات الثلاثة الباقية للمرجع فقط — لا ترفعها)
4) Render سيعيد التشغيل وحده (دقيقتان تقريباً).
5) في التطبيق: شارة «يتوفر تحديث v58» ← «نعم، حدّث الآن».

تجربة سريعة بعد التحديث:
─────────────────────────────────────────
أي محادثة ← أرسل فيديو ← اضغط بطاقة ▶ فيشتغل داخل
الدردشة. «＋ محادثة جديدة» ← ابحث باسم أي عميل أو @اسمه.
و«⬆️ الرسائل الأقدم» يجلب التاريخ كله.

هل أحتاج تثبيت أي شيء على الهاتف؟
─────────────────────────────────────────
لا. التحديث يصل من داخل التطبيق بنقرة «نعم، حدّث الآن»
كالعادة — نفس الأيقونة، نفس الدخول، بلا أي تنزيل جديد.
