   تظهر له صلاحياته الجديدة في تطبيقه تلقائياً —

2) افتح لوحة Render ← خدمتك (produit).
3) ارفع الملفين:
      bot.py     ← مكان bot.py القديم
      pwa.html   ← مكان pwa.html القديم
   (الملفات الثلاثة الباقية للمرجع فقط — لا ترفعها)
4) Render سيعيد التشغيل وحده (دقيقتان تقريباً).
5) في التطبيق: شارة «يتوفر تحديث v63» ← «نعم، حدّث الآن».
6) جرّب: رقِّ أي مستخدم ثم اطلب منه العودة للتطبيق —
   سيرى فئته الجديدة وحده دون إغلاق شيء.
