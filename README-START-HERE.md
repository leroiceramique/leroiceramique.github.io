 ابدأ هنا — تحديث v55 (تسجيل صوتي فوري بلا أي نوافذ)
═══════════════════════════════════════════════════════

نفس التطبيق الذي اخترناه — تحديث من الداخل، لا APK جديد.

ماذا يفعل هذا التحديث؟
─────────────────────────────────────────
1) حذف واجهة «التسجيل مثل واتساب» القديمة نهائياً
   (لا تعليمات، لا كروم، لا مسجّل هاتف، لا ملفات جهاز).
2) زر 🎤 = ضغط مطول حقيقي: تسجيل فوري، عداد ثوانٍ داخل
   شريط الرسائل، الإفلات يُرسل مباشرة، السحب لليسار يلغي.
3) رسالة صغيرة فقط إذا رُفض إذن الميكروفون.

الخطوات (نفس طريقتك المعتادة في Render):
─────────────────────────────────────────
1) فك الضغط — ستجد 5 ملفات.
2) افتح لوحة Render ← خدمتك (produit).
3) ارفع الملفين:
      bot.py     ← مكان bot.py القديم
      pwa.html   ← مكان pwa.html القديم
   (الملفات الثلاثة الباقية للمرجع فقط — لا ترفعها)
4) Render سيعيد التشغيل وحده (دقيقتان تقريباً).
5) في التطبيق: شارة «يتوفر تحديث v55» ← «نعم، حدّث الآن».

تجربة سريعة بعد التحديث:
─────────────────────────────────────────
أي محادثة ← اضغط 🎤 ضغطة مطولة وتكلم ← أخلِ إصبعك فيُرسل.
اسحب إصبعك لليسار أثناء الضغط ← إلغاء وحذف التسجيل.

هل أحتاج تثبيت أي شيء على الهاتف؟
─────────────────────────────────────────
لا. التحديث يصل من داخل التطبيق بنقرة «نعم، حدّث الآن»
كالعادة — نفس الأيقونة، نفس الدخول، بلا أي تنزيل جديد.
