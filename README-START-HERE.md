 ابدأ هنا — تحديث v59 (مركز تشخيص الميكروفون)
═══════════════════════════════════════════════════════

نفس التطبيق — تحديث من الداخل، لا APK جديد.

ماذا يفعل هذا التحديث؟
─────────────────────────────────────────
عند أي فشل للميكروفون يفتح التطبيق لوحة «🎤 فحص
الميكروفون» تريك السبب الدقيق على جهازك (الإذن،
الميكروفونات المكتشفة، مرات الفشل) + زر فحص فوري +
خمس خطوات إصلاح مرقمة + زر يرسل لي تقريراً كاملاً
في تلغرام.

الخطوات (نفس طريقتك المعتادة في Render):
─────────────────────────────────────────
1) فك الضغط — ستجد 5 ملفات.
2) افتح لوحة Render ← خدمتك (produit).
3) ارفع الملفين:
      bot.py     ← مكان bot.py القديم
      pwa.html   ← مكان pwa.html القديم
   (الملفات الثلاثة الباقية للمرجع فقط — لا ترفعها)
4) Render سيعيد التشغيل وحده (دقيقتان تقريباً).
5) في التطبيق: شارة «يتوفر تحديث v59» ← «نعم، حدّث الآن».

تجربة سريعة بعد التحديث:
─────────────────────────────────────────
📎 المرفقات ← «🎤 فحص الميكروفون» ← «🔍 فحص الآن».
إن ظهر ✅ فالتسجيل يعمل. إن ظهر ❌ طبّق الخطوات المرقمة
بالترتيب (إعادة تشغيل الهاتف أولاً) وافحص بعد كل خطوة.

هل أحتاج تثبيت أي شيء على الهاتف؟
─────────────────────────────────────────
لا. التحديث يصل من داخل التطبيق بنقرة «نعم، حدّث الآن»
كالعادة — نفس الأيقونة، نفس الدخول، بلا أي تنزيل جديد.
