نسخة الواجهة الأمامية — GitHub Pages (مولَّدة آلياً من bot.py v135)
================================================================

الملفات المطلوب رفعها إلى مستودع leroiceramique.github.io:
  index.html              واجهة التطبيق كاملة
  manifest.webmanifest    إعدادات تطبيق PWA
  sw.js                   عامل الخدمة (شبكة أولاً)
  icon.jpg                أيقونة التطبيق

خطوات النشر (مرة واحدة):
  1) سجّل حساب GitHub باسم leroiceramique إن لم يكن موجوداً.
  2) أنشئ مستودعاً عاماً باسم: leroiceramique.github.io
  3) ارفع الملفات الأربعة أعلاه إلى الجذر (Add file → Upload files → Commit).
  4) انتظر دقيقة ثم افتح:  https://leroiceramique.github.io

عنوان الخادم المضمَّن في هذه النسخة:
  (غير مضمَّن — تظهر شاشة ضبط لمرة واحدة عند أول فتح، وأدخل عنوان الخادم فيها)

لتغيير عنوان الخادم لاحقاً دون إعادة النشر:
  افتح  https://leroiceramique.github.io/?api=العنوان_الجديد
  (يُحفظ في الجهاز فوراً) — أو أعد التصدير من التطبيق (مدير):
  https://<عنوان-الخادم>/api/pages/export ← ZIP مطابق دائماً للخادم الحي.

ملاحظات:
  - كل وظائف التطبيق تعمل من هذا النطاق: دخول، جلسات 90 يوماً، تذكّر 180 يوماً،
    مخزون، مستودع، فواتير، رسائل، مصروفات — الاتصال بالخادم عبر HTTPS مؤمّن.
  - لا حاجة لفتح رابط Render إطلاقاً؛ هذا النطاق هو العنوان الوحيد للمستخدم.
